# Windows 10/11 使用说明

## 安装和打开

1. 从 [python.org](https://www.python.org/downloads/windows/) 安装 Python 3.10 或更新版本，推荐 3.13，保留 Tcl/Tk、pip 和 Python Launcher 组件。
2. 将 ZIP 完整解压到可写文件夹，关闭旧助手，双击新文件夹内的 `start_windows.bat`。不要直接在压缩包里运行。
3. 首次启动会检查项目 `.venv` 和 pip，安装固定版本的 Pillow 12.0.0、uiautomation 2.0.29、comtypes 1.4.17；以后复用正常环境。无须管理员权限。
4. 在右上角“AI 设置”填写密钥。默认是 OpenAI API / `gpt-4.1-mini`，需要单独开通 API 额度，ChatGPT 订阅不包含 API 额度。密钥默认仅在本次运行保留；Windows 可主动勾选记住密钥，由当前 Windows 用户加密保存。不要把密钥发到聊天里。

这是需要 Python 的桌面脚本包，不是独立 EXE，不需要部署网站。

## 先建立会话背景和记忆

1. 在顶部“当前会话”旁点“新建”，输入联系人或聊天的名称。不同联系人使用不同名称，避免混用历史。
2. 在“背景与记忆”填写双方关系、已确认的背景和沟通目标。例如：“同事；正在协调下周会议；希望确认时间，但不要替我承诺周末有空。”只写你确认的事实；也可直接在主界面填写本次沟通目标。
3. 点“保存资料”。默认这些记忆只留在本次运行；是否退出后继续保存，可在同一窗口明确选择。
4. 初次使用时，先补充必要的过去聊天。可以在微信复制最近消息，点“粘贴聊天”或直接在左侧粘贴，标清“我 / 对方”，检查内容后生成。

助手不知道安装前或从未导入的历史。背景由你填写；历史来自你确认分析的文字和明确标记的已发送内容，不会凭空取得微信的全部记录。聊天文字进入会话记忆后，即使生成请求失败，也仍保留在该会话中，便于重试。

## 一键分析当前微信会话

1. 在助手选择对应的“当前会话”。不要使用“临时会话（不记忆）”。
2. 打开电脑版微信，进入对应聊天，保持窗口还原并显示近期消息。
3. **核对微信当前联系人与助手所选会话一致**，点“一键分析当前聊天”。只有一个可用微信窗口时自动选择；有多个窗口时会让你选择一次，也可在“更多工具”的下拉框中指定。
4. 成功时会读取当前消息列表公开的文字，清除本次附加图片，合并所选会话的背景和历史后调用 AI。程序不能可靠核实联系人身份，切换微信聊天后也要切换助手会话。
5. 核对右侧理解摘要，再编辑回复。读到的文字也可在左侧修改后重新生成；无法确定发言者时，不要把模型推断当成事实。
6. 点“复制回复”，回微信粘贴并自行发送；也可启用“生成后复制”，省去复制按钮。确实发出后，再回助手点“记为已发送”并确认。这一步只是补充会话历史，不会代你发消息。

文字读取最多尝试约 8 秒，只读取可访问消息区域的近期可见条目，最多 100 条、12000 字，不自动翻页。它不读取联系人列表、微信数据库或后台消息，也不注入客户端。

**你使用的微信 4.1.15.13 尚未完成实机兼容性验证。** 是否能直接读到文字，取决于微信是否向 Windows 辅助功能公开消息列表。当前读取器只接受明确命名的消息列表；没有可读列表、列表为空或目标不明确时会停止并提示，不提交 AI，也不会自动退回截图分析。

如果这个版本不提供消息文字，当前的一键读取就无法完成。可先复制近期聊天文字导入，验证会话记忆和回复效果；不能把这一步描述为已经自动接入微信。

## 定时检查并生成草稿

选好命名会话、配置 AI 并打开对应微信聊天后，点“开启自动辅助”。程序默认每 10 秒检查一次当前选定窗口，有新内容时生成草稿；无需每条消息再点读取和生成。在“更多工具”可将间隔改为 5、10、20 或 30 秒。

状态栏会显示检查、等待和暂停原因。“暂停自动辅助”始终保留，可以在读取或等待 AI 时点击。暂停后，仍在进行的读取或生成结果会被忽略；重新开启需要你操作，重启助手也不会自行开启。

- 相同内容不会反复调用 AI；只是在消息列表中回看旧内容，也不会当作新消息。检查与生成按顺序处理，不会积压多个并发请求。
- 当前草稿未处理时，新内容先等待，不覆盖你的修改；复制草稿或明确记为已发送后，才继续生成。启用自动复制后再次编辑草稿，也会重新等待你处理。
- 自动辅助绑定所选命名会话及微信窗口。切换助手会话、窗口变化、窗口关闭或读取失败时会暂停；消息上下文完全不连续时，也会先暂停，避免继续合并陌生内容。
- **保持微信停留在已允许的聊天；切换联系人前先暂停。** 同一个微信窗口内的联系人身份仍无法可靠核实；窗口和上下文检查不能保证识别所有聊天切换。
- 自动辅助依赖同一套文字读取能力。微信不公开消息文字时，它不会绕过限制、反复报错或改为后台截图。

“生成后复制”为可选项，默认关闭。打开后会用新草稿替换剪贴板文字，方便你回微信粘贴；复制不等于已经发送。自动辅助不点击微信、不自动发文字或图片，表情包仍需你手动保存和发送。

## 记住设置与 API 密钥

接口地址、模型、自动复制开关和检查间隔保存在 `%LOCALAPPDATA%\JieHua\settings.json`。开启会话记忆的本地保存后，助手也可恢复上次选择的已有会话；自动辅助的运行状态不保存。

API 密钥默认仅用于本次运行。Windows 的“AI 设置”提供明确的记住密钥选项，使用当前 Windows 账号的 DPAPI 加密后保存；文件中不写明文密钥。取消记住并保存会移除已保存的加密密钥，当前运行仍可继续使用已填写的值。该功能不支持在其他 Windows 账号或其他系统间迁移密钥；解密失败时应重新填写。

桌面设置、会话文字记忆和表情收藏彼此独立。关闭会话文字保存不会删除设置中的加密密钥或表情图片；如不再需要记住密钥，请在“AI 设置”单独取消。

## 自定义接口与 HTTP 地址

1. 在“AI 设置”填写服务商提供的接口地址、模型 ID 和密钥。接口需要支持 OpenAI 兼容聊天格式；模型名称以该接口提供的 ID 为准。
2. 地址填写到 `/v1` 等前缀，例如 `http://your-api-host/v1`；不要附加 `/chat/completions`，程序会自行补全。复制地址时末尾的空白会去除。
3. 使用 HTTP 时，明确勾选“允许此 HTTP 地址”。**HTTP 会明文传输密钥和聊天内容**，请确认信任地址及网络；服务商提供有效 HTTPS 地址时可优先使用。更换地址会清除此开关，HTTPS 证书校验不会关闭。
4. 点“测试接口”，获取可用模型列表；不会提交聊天或生成回复。当前名称仅大小写不一致时，会按服务返回值校正；其他情况可从模型下拉框选择。
5. 点“保存并继续”，先粘贴一段文字测试生成。截图还要求模型支持图片输入，模型列表可访问也不代表所有生成格式都受支持。

部分中转接口不提供 `/models`，测试出现此提示时仍可保存后尝试生成。认证失败、模型不存在、生成格式不兼容是另外的问题，需要依据实际返回结果区分；不要把密钥发到聊天里。HTTP 授权随对应地址保存，API 密钥仍遵守上面的独立保存选项。

## 回复速度和显示内容

默认模式为“先给 1 条（较快）”，也可选“生成 3 条候选”。AI 对上下文的理解和草稿在同一次请求中生成，结果完整返回后显示，不是流式逐字输出。

文字流程不再每次上传图片，近期历史和生成长度也有限制。界面会显示等待时长及生成用时，但没有真实 API 速度基准，不能承诺几秒完成。网络、模型、输入长度和图片都会影响速度。可先使用简短文字、单条回复模式比较实际等待时间。

截图导入本身不需要密钥；一键分析及自动辅助包含后续 AI 调用，因此需要先配置有效密钥。

## 组合自己的表达风格

在顶部点“表达风格”，分别选择：

- **我的表达倾向**：中性、偏男性化、偏女性化。这是写作偏好，不代表实际性别，也不用于推断聊天对象的身份。
- **性格表达**：自然、温柔体贴、直率爽快、理性克制、活泼外向、慢热内敛、俏皮毒舌。
- **幽默、玩梗和抽象程度**：每项独立设置为 0–3，0 表示不刻意使用，3 表示强度较高。

也可选择“稳妥日常”“轻松有梗”“抽象搞怪”预设，再单独调整。点“应用风格”后，下次生成生效，已有草稿不会自动改写。命名会话分别记住各自的组合；需要退出后恢复时，仍要在“背景与记忆”开启本地保存。严肃、道歉或难过的话题会按场合收敛玩梗，不保证每条回复都带梗。

## 表情包候选：先看图，再手动保存和发送

适合配图时，模型会在生成回复的同一次请求中附带表情主题和简短标签；不合适时可以没有建议，不会为了凑数强行推荐。右下角点“找个表情”可浏览图片。主题和标签用于匹配分类、文件名及本地标签，**不是理解每张图片内容的视觉搜索**；候选是否合适仍需你看图判断。

本地图片可以通过文件选择框明确导入，支持 PNG、JPEG、GIF、WebP，每次 1–20 张、每张不超过 10 MB。你可以添加标签，方便之后根据主题挑选。图片会复制到 `%LOCALAPPDATA%\JieHua\memes`，以后打开助手仍可浏览；这与会话文字的本地保存开关独立。删除本地表情只删除库副本，不删除当初导入的原图。

也可明确点击联网查找，从 [ChineseBQB](https://github.com/zhaoolee/ChineseBQB) 的公开分类包中获取图片，不需要额外图库密钥。助手只请求固定公开资源包，不把原始聊天发给图库；按主题、标签、分类或文件名选择候选，匹配结果不代表图片一定符合当时情境。

网络候选只在本次窗口内存中暂存。需要保存到指定位置或加入本地收藏时，由你主动点击相应操作；浏览或联网查找本身不等于收藏。候选会显示来源链接。GIF 在界面中只预览首帧，手动保存时保留原始动图文件，不会自动转为静态图片。

所有表情都由你手动保存，再自行在微信选图发送；助手不会代发、点击微信发送按钮，或把浏览图片记成已发送消息。公开源和网络可能不可用，失败时会提示，不会显示伪造的下载结果。

## 保存、查看和删除记忆

“背景与记忆”显示当前会话的背景、目标及已记录历史。不同会话分别保存，模型生成的候选草稿和复制操作不会自动写成已发送事实。

- **只在本次运行记忆**：默认行为，退出后丢失未保存的会话资料。
- **本地保存开关**：勾选后点“保存资料”，将所有命名会话的文字资料以明文保存到 `%LOCALAPPDATA%\JieHua\conversations.json`。重新打开助手时可以恢复；请按自己的设备使用情况决定是否开启。
- **关闭本地保存**：取消勾选并点“保存资料”，会删除应用保存的记忆文件，但本次运行中的会话仍在。
- **清空本次内容**：只清除当前输入、截图和草稿，保留会话的关系、目标和历史。
- **清空历史**：删除当前会话已记录的聊天，保留背景、关系和目标；如果开启本地保存，也会更新磁盘文件。
- **删除会话**：删除该会话的背景和全部历史；其他会话不受影响。

会话风格随上述会话资料保存或删除。表情库是另一份明确导入的本地收藏，关闭文字记忆保存或删除会话不会删除这些图片；请在表情候选窗口管理库副本。

历史有长度上限，会保留近期内容并合并重叠导入片段，并非完整微信档案。截图和 API 密钥不写入会话记忆，也不会自动从截图提取并长期保存事实。生成时会把当前输入和所选会话的记忆提交到配置的 AI 服务；服务商的数据保留政策另行适用。

## 备用：导入截图

当文字读取不支持时，可自行决定是否使用图片：

1. 在微信打开聊天，按 **Win+Shift+S**，或展开助手的“更多工具”点“系统截图”，框选消息区域。
2. 从任务栏回助手，点“导入剪贴板截图”。若没有图片，先打开截图并按 Ctrl+C。
3. 在预览中拖动框选允许分析的区域，点“确认使用选区”。截图缩略图出现表示已附加成功；左侧不会自动填入识别文字。
4. 核对所选会话、文字和图片，填写意图，再用编辑内容生成。不需要的旧文字或图片应先清除。

本次最多附加一张图，最长边缩小到 2000 像素。图片只用于本次生成；如果希望某个事实进入后续记忆，应在“背景与记忆”中填写，或把相应文字导入。主界面保留聊天和草稿；展开“更多工具”后可以滚动查看备用采集选项。

## 常见问题

- **没有可读取的消息列表**：先确认已打开具体聊天、窗口未最小化；仍不支持时，说明此微信画面没有公开读取器需要的文字。复制文字导入即可继续测试记忆功能，不需要关闭系统保护或修改微信。
- **“未能采集到窗口内容”，但微信明明已打开**：这是备用窗口截图得到空白或纯色画面，不是没找到微信。部分微信画面不能用这种方式截图；可改用手动系统截图。它与文字读取是两种不同的尝试。
- **AI 不知道以前聊过什么**：检查是否选对命名会话，确认相关文字确实导入过，并在“背景与记忆”查看记录。没有开启本地保存时，重启后不会保留；从未导入的历史也不会自动出现。
- **自动辅助暂停了**：先看状态栏原因。窗口关闭、读取失败、切换会话或上下文不连续都会暂停；核对微信当前聊天与助手会话后，再主动开启。增加检查频率不能解决微信不公开消息文字的问题。
- **复制了草稿，却没记到“我已发送”**：这是为了避免把未发送的内容当成事实。只有实际发送后，明确点“记为已发送”才记录。
- **`No module named 'pip._vendor.rich._extension'`**：pip 缺少内部文件，程序尚未进入微信功能。新启动器会将旧 `.venv` 完整保留为 `.venv.backup-时间-编号`，在最终路径重建一次，不删除 `.env` 或旧文件。
- **新环境的 pip 仍无法运行**：运行 python.org 官方 Python 安装程序选择 Modify/Repair，或重新安装包含 pip、Tcl/Tk 的 Python 3.13。单独 `ensurepip --upgrade` 可能因版本相同而跳过缺失文件；不要关闭 TLS 或包校验。
- **文字读取组件缺失**：关闭助手，再运行新版本的 `start_windows.bat`。它会检查并安装 Windows 专用依赖；不要覆盖正在运行的旧文件。
- **网络安装失败**：确认可访问 `pypi.org`、`files.pythonhosted.org`，保留错误信息后重试。网络失败不触发重复重建；已有环境被占用时先关闭相关助手和终端，启动器不会强行结束进程。
- **生成报错或一直等待**：检查 API 密钥、额度、模型和网络。默认 OpenAI API 与 ChatGPT 订阅分别计费；文字流程需要 JSON 输出和 `max_tokens`，图片备用还需视觉输入支持。

可用 `py -3.13 bootstrap_desktop.py --setup-only` 单独准备环境。环境备份目录默认忽略，不提交 Git。

## 验证范围

环境准备、会话记忆、提示组装、输出解析、周期检查去重和暂停、设置保存及桌面交互有自动化测试。Windows 辅助功能文字读取和密钥加密使用替身验证分支，真实 API、DPAPI 及微信 4.1.15.13 仍需实机验证。测试成功不代表已经取得个人微信官方消息接口。
