# Windows 10/11 使用说明

## 第一次打开

1. 从 [python.org](https://www.python.org/downloads/windows/) 安装 Python 3.10 或更新版本，保留默认的 Tcl/Tk、pip 和 Python Launcher 组件。
2. 将项目或下载的 ZIP 完整解压到自己可写入的文件夹。不要直接在压缩包里运行。
3. 双击 `start_windows.bat`。启动器优先使用已安装的 Python 3.13，否则使用系统默认 Python 3。首次创建项目内的 `.venv` 并检查 pip，再从 PyPI 安装固定版本的 Pillow；之后启动会复用正常环境。无须管理员权限。
4. 点击窗口右上角“AI 设置”填写 AI API 密钥。默认接口是 OpenAI，模型为 `gpt-4.1-mini`，需要单独开通 API 额度；ChatGPT 订阅不包含 API 额度。密钥仅在本次运行保留，关闭后需重新输入。不要把密钥发到聊天里。

这是一份需要 Python 的桌面脚本包，不是已签名的独立 EXE 安装包。不需要部署网站、开启公网端口或使用云端可视化预览。

## 推荐操作：用系统截图导入聊天

采集聊天不需要 AI 密钥；密钥只在生成回复时使用。

1. 打开微信，进入需要分析的聊天，让消息显示在屏幕上。
2. 在助手点击“系统截图（推荐）”。助手会最小化，打开 Windows 截图工具；也可直接按 **Win+Shift+S**。
3. 拖动框选微信聊天消息区域，松开鼠标，截图会进入剪贴板。无需截取整个桌面。
4. 从任务栏回到助手，点击 **“导入剪贴板截图”**。如果剪贴板没有图片，请打开刚才的截图，按 Ctrl+C，再导入。
5. 在弹出的预览里再次拖动框选允许分析的聊天区域，点击“确认使用选区”。看到助手中的截图缩略图，即表示已附加成功。
6. 填写回复意图和语气，勾选允许提交给 AI，再点击生成。此时需要配置有效 AI API 密钥。
7. 编辑候选回复，点击复制，再回微信粘贴并确认发送。

**截图附加后，左侧文字框不会自动出现识别文字。** AI 会在点击生成后分析附加截图。只有截图也能生成，不必重复输入聊天文字。

小屏幕上可使用左侧滚动条，向下查看截图和回复意图输入区。确认框和“生成”按钮固定在窗口底部。

## 可选操作：直接采集微信窗口

1. 打开 Windows 微信并登录，切到你允许分析的会话，让近期消息显示在窗口中。
2. 在助手点“查找微信”，明确选择对应窗口，再点“采集选中窗口”。
3. 采集时按钮显示进度，约 8 秒后仍不能完成会弹出说明。成功后，在预览中拖动框选**聊天消息区域**，排除左侧联系人列表等无关内容，点“确认使用选区”。此时还没有向 AI 提交内容。
4. 输入想表达的意思，例如“委婉拒绝，别留下下次一定的承诺”，选择语气，必要时补充双方关系。
5. 检查附加的聊天选区和文字，勾选确认发送给 AI，再点击生成或按 Ctrl+Enter。
6. 三条草稿可直接编辑。点击“复制这条回复”，切回微信粘贴，自行确认发送。

每次采集需主动点击；不会轮询、读取微信数据库、注入客户端或自动发送。直接窗口采集也采用**截图 + 视觉模型分析**，不是通过微信 API 读取完整历史。只分析可见且由你框选的上下文，不自动翻页。

## 两种备用导入方式

- **复制文字**：在微信选择并复制需要的消息，点“导入复制文字”；也可在左侧文本框按 Ctrl+V。多人聊天请标明说话者。一次最多 20000 字。
- **微信截图 / 系统截图**：用微信截图或 Win+Shift+S 截取聊天，复制截图后点“导入剪贴板截图”，再框选确认。本次最多附加一张截图，最长边压缩至 2000 像素。

文字和截图可以一起提交。生成前会发送当前文本及当前截图，而不是自动替换其中一个；不需要的内容请手动清空或移除。应用不保存聊天和 API 密钥到磁盘，AI 服务可能根据其政策保留请求。清空应用不会清除系统剪贴板，复制的内容仍由 Windows 剪贴板管理。

## 常见问题

- **找不到微信窗口**：当前按 `WeChat.exe` / `Weixin.exe` 进程匹配。先登录并打开窗口；特殊客户端、不同进程名或权限差异需要另外适配。可先使用复制文字或截图导入。
- **“未能采集到窗口内容”，但微信明明已打开**：这表示已找到窗口，但取到的画面是一片空白，不表示微信没打开。部分微信版本的画面绘制方式不支持这种窗口截图。请使用上面的“系统截图（推荐）”流程；反复重新打开微信、先填 AI 密钥都不能保证解决此问题。
- **截图空白 / 黑屏 / 内容不完整**：保持微信还原并显示聊天，尽量不被其他窗口遮挡；仍失败时用微信自带截图或系统截图。原生窗口采集失败或超时都会显示弹窗，不会退回到截取整个桌面。
- **截图已附加，文字框却是空白**：这是正常行为。本版直接向视觉模型提交选定的图片，不先做本地文字识别。填写回复意图，确认后点击生成即可。
- **用的是旧版，仍只有底部提示**：关闭旧助手，重新下载 ZIP 并解压到新文件夹，再启动其中的 `start_windows.bat`。不要覆盖旧目录中正在运行的文件。
- **密钥错误、额度不足或模型不存在**：检查“AI 设置”。接口必须为 HTTPS、兼容 OpenAI `/chat/completions`；截图需要支持 `image_url` 的视觉模型，所有回复需要 JSON 输出支持。网络不可达时明确报错，不会生成假回复。
- **缺少 Python 或 Tk**：重新安装官方 Python 并勾选 Tcl/Tk；不要通过 `pip install tkinter` 安装。
- **`No module named 'pip._vendor.rich._extension'`**：这是项目虚拟环境中的 pip 缺少内部文件，发生在依赖安装阶段，与微信采集和 API 密钥无关。新启动器会检查 pip，把损坏的 `.venv` 完整保留为 `.venv.backup-时间-编号`，再在原路径重新创建一次。不会删除代码、`.env` 或旧环境中的文件。
- **新建环境的 pip 仍不能运行**：不要反复重试或关闭校验。运行从 python.org 下载的官方 Python 安装程序，选择 Modify/Repair；或重新安装包含 pip 和 Tcl/Tk 的 Python 3.13，然后再启动。单独运行 `ensurepip --upgrade` 可能因版本相同而跳过缺失文件，不能保证修好。
- **首次依赖下载失败**：保留终端的错误信息，确认能连接 `pypi.org` 和 `files.pythonhosted.org`。不要关闭 TLS 或包校验。

新启动器的环境准备逻辑位于 `bootstrap_desktop.py`，也可通过 `py -3.13 bootstrap_desktop.py --setup-only` 单独运行。备份目录默认忽略，不会提交到 Git。若原 `.venv` 正被其他进程占用，先关闭相关助手和终端，启动器不会强行结束进程。网络下载失败不会触发重复重建。

## 当前验证范围

Linux 云环境安装了固定版本 Pillow，桌面 UI 使用虚拟显示器验证。Windows 微信窗口枚举和捕获使用替身验证选定窗口身份、最小化窗口拒绝、失败时不截取整个桌面等分支；另验证采集超时、可见错误提示和系统截图操作入口。**真实 Windows 10/11 微信版本尚未实机验证，真实 AI 调用也仍需有效密钥。**
